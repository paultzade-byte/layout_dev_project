# Оптимізатор української розкладки

Програма шукає зручнішу українську розкладку клавіатури. Вона оцінює, наскільки
незручно друкувати *справжні українські тексти* тією чи іншою розкладкою, і
перебирає варіанти методом імітації відпалу (simulated annealing), доки не
знайде кращий. Працює для звичайної клавіатури (ANSI) і для розділеної
клавіатури Corne (42 клавіші).

## Чим відрізняється

- **Зроблено саме під українську мову.** Наскільки відомо автору, інструмента,
  що оптимізує розкладку саме під українську, досі не було.
- **Загальна статистика мови, а не один текст.** Більшість аналізаторів розкладок
  рахують зручність на тексті, який ти їм даси. Ця програма спирається на
  статистику великого корпусу української (UberText, ~16 ГБ): частоти літер,
  біграм, триграм і скіп-грам, а для серій натискань однією рукою — частоти слів.
  Тож враховано не лише найчастіші літери, а й **літери середньої частоти**.
  На короткому тексті вони трапляються випадково, а на розкладку впливають
  помітно.
- **Модель руки, а не лише частоти:** домашній ряд, вертикальні переходи одним
  пальцем, навантаження на мізинці, перекати і чергування рук, цілі слова,
  набрані однією рукою.
- **Зрозумілі повзунки замість десятків ваг:** «Домашній ряд», «Берегти
  мізинці», «Перекати ↔ чергування рук» тощо. Є готові пресети («Мінімум змін від
  ЙЦУКЕН», «Бережу мізинці», «Більше перекатів»), можна зберегти свій.
- **Близькість до ЙЦУКЕН.** За бажання оптимізатор тримає літери ближче до
  звичних місць, щоб було легше перевчитись.
- **Готово до встановлення в систему:** «Експорт…» дає файли для Windows
  (`.klc` для MSKLC), Linux (xkb) і macOS (`.keylayout`) з інструкцією.
- **Для Corne з ZMK:** розкладку можна записати на клавіатуру і прочитати з неї
  по USB (кнопки «На клаву» / «З клави»).
- **Своя статистика текстів:** програма «Статистика текстів» (`ukr-stats.exe`,
  `python -m uiux.stats_app`) рахує частоти літер і їхніх пар з ваших власних
  текстів (тека з `.txt`) — і оптимізатор підбирає розкладку саме під них
  (кнопка «Статистика ▾»). Мова визначається сама (українська, білоруська,
  польська); оптимізатор поки працює з українською.
- **Для звичайних людей:** exe для Windows, підказки при наведенні на кожну
  кнопку, перетягування клавіш мишкою, заморожування клавіші правою кнопкою.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m uiux.app            # вікно програми
python -m uiux.stats_app      # статистика власних текстів
python main.py --geometry generic_105_alpha --iterations 20000   # без вікна
```

Windows: exe збирає GitHub Actions (`Build Windows`; у теці `ukr-layout.exe` і
`ukr-stats.exe`): архів `ukr-layout-windows`
у артефактах запуску або в Release для тегу `v*`.

## Як це влаштовано

- `core/scorer.py` — оцінка розкладки (менше — краще), `core/mutator.py` —
  пошук (імітація відпалу + tabu), `core/knobs.py` — повзунки і пресети.
- `config/statistic.json` — статистика n-грам корпусу, `config/word_stats.json` —
  частоти слів; ваги штрафів — `config/moves.yaml` (Corne) і
  `config/moves_standard.yaml` (ANSI).
- `uiux/` — вікно (Tkinter), `core/export.py` — експорт в ОС.
