Тестова версія для Windows 10/11.

**Як запустити**
1. Скачайте `ukr-layout-windows.zip` (нижче, в Assets) і розпакуйте в будь-яку теку.
2. У теці `ukr-layout`: `ukr-layout.exe` — оптимізатор розкладки, `ukr-stats.exe` — статистика ваших текстів.
3. Ярлики на робочому столі й у «Пуск» — подвійний клік на «Створити ярлики.bat» («Видалити ярлики.bat» — прибрати).

Windows може попередити «Захистив ваш ПК» (програма без цифрового підпису) — «Докладніше» → «Виконати в будь-якому разі».

**Як перевірити, що файл справжній**

Архів зібрано автоматично на серверах GitHub з відкритого коду цього репозиторію — ось ця збірка: {RUN_URL}

SHA-256 архіву:
```
{SHA256}
```
Перевірка (PowerShell у теці зі скачаним файлом):
```
Get-FileHash ukr-layout-windows.zip
```
Має збігтися з рядком вище (регістр літер не важливий). Хеші самих exe — у `SHA256SUMS.txt`.

Для тих, хто має [GitHub CLI](https://cli.github.com/) — перевірка підпису походження (що архів зібрав саме цей репозиторій, а не хтось інший):
```
gh attestation verify ukr-layout-windows.zip -R {REPO}
```

Знайшли помилку чи щось незручно — напишіть, що робили і що побачили (скрін дуже допоможе).
